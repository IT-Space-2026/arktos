Install semantics
-----------------
Installed once per non-off-the-record profile by
ExtensionManager::installBundledExtensions().  On an extension-fresh
profile it is enabled as part of the install; on a profile that
already carries installed extensions it lands installed-but-disabled
(opt-in via Preferences -> Extensions).  Removing it is never
reinstalled — the per-profile marker in QSettings
("extensions/bundled/<storageName>") is one-shot.
