# Arora SEC18 domain blocklist — vendored seed.

# Local anti-phishing/malware list: matched as exact-host + suffix
# (a listed "dom.ain" blocks "dom.ain" and "*.dom.ain").  This seed
# ships with the binary so blocking works fully offline; the updater
# (consent-gated, TELEM01) merges fresh feeds into
# <data dir>/blocklist-domains.txt, and the runtime set is the UNION
# of this file plus the override — an update can only add coverage,
# never quietly unblock a seed domain.
#
# Row shapes the parser accepts (upstream feeds drop in unchanged):
#   plain.example                     bare domain
#   127.0.0.1<TAB>dom.ain             hostfile rows (URLhaus)
#   https://dom.ain/path?query        URL rows (OpenPhish)
#   ||dom.ain^  /  *.dom.ain          adblock-style decorations
#
# Update sources:
#   https://urlhaus.abuse.ch/downloads/hostfile/   (malware, abuse.ch)
#   https://openphish.com/feed.txt                  (phishing, community)
